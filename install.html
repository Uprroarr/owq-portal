Install OWQ Station

Put the command station on your computer or phone like normal software: its own window, an icon on your desktop, Start menu, Dock or home screen, and it opens straight to the portal. Sign in once with your Google account, same as the website.

Open in the browser

Works in Chrome and Edge (Windows, Mac, Chromebook, Android) and Safari (Mac, iPhone, iPad). Free, nothing to download from outside your browser, updates itself.

Installed. Open OWQ Station from your desktop, Start menu, Dock or home screen.
Windows

Chrome or Edge

  1. Click Install OWQ Station above,
  2. or use the install icon at the right end of the address bar,
  3. or Edge: ... → Apps → Install this site as an app.
Mac

Safari, Chrome or Edge

  1. Safari: File → Add to Dock → Add.
  2. Chrome / Edge: click Install OWQ Station above.
iPhone & iPad

Safari

  1. Tap Share (square with the arrow).
  2. Tap Add to Home Screen → Add.
Android

Chrome

  1. Tap Install OWQ Station above,
  2. or ⋮ → Install app.
